Catalog V2 Troubleshooting Guide

HTTP 401 errors usually indicate an expired or invalid OAuth2 access token.

Applications should verify that the client ID and client secret are valid.

HTTP 429 errors indicate that the application has exceeded the API rate limit.

The recommended retry strategy for rate limiting is exponential backoff.

CAT-V2-ERROR-5001 indicates an internal catalog synchronization failure.

If CAT-V2-ERROR-5001 persists for more than 15 minutes, contact the Catalog Platform support team.
