Catalog V2 Migration Guide

Catalog V2 replaces the legacy Catalog V1 service.

Applications migrating from Catalog V1 must update the base API endpoint from /api/v1/catalog to /api/v2/catalog.

Catalog V2 uses OAuth2 client credentials authentication. Legacy API keys used by Catalog V1 are not supported.

Access tokens are valid for 60 minutes. Applications should request a new token before the existing token expires.

The product identifier field productId has been replaced by catalogItemId.

Migration error CAT-V2-ERROR-4097 occurs when an application sends the deprecated productId field.

To resolve CAT-V2-ERROR-4097, replace productId with catalogItemId in the request payload.
